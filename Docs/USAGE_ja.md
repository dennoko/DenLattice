# Dennoko Lattice 使い方

VRChat アバター改変向けの、非破壊ラティス変形ツールです。
3Dの格子（ラティスボックス）の制御点を動かすだけで、服の体型合わせやプロポーション調整を滑らかに行えます。元のメッシュファイルは書き換えません。

## 必要環境

- Unity 2022.3.22f1 以降
- VRChat SDK
- **NDMF (nadena.dev.ndmf)** — 必須

---

## Quick Start

### 1. コンポーネントの追加
ヒエラルキーで編集したいメッシュ（SkinnedMeshRenderer / MeshRenderer）を右クリックし、`dennokoworks > Dennoko Lattice` を選択します。

### 2. 編集モードの開始
Inspector の **「編集開始」** ボタンを押します。※メッシュに右クリックから追加した場合は自動で編集モードに入ります。

### 3. 編集
シーンビューに表示される制御点をクリック（またはドラッグで矩形選択）し、移動ハンドルで動かします。

### 4. 編集モードの終了
Esc キーを押すか、Inspector またはシーンビュー内の操作パネルで「編集終了」を押します。

## 詳しい使い方

### 1. コンポーネントを付ける

ヒエラルキー上で編集したいメッシュを持つオブジェクトを右クリックし、`dennokoworks > Dennoko Lattice` を選択します（または Inspector の `Add Component` から追加します）。

- **Renderer を持つオブジェクトに右クリックから追加した場合：**
  そのメッシュが自動的に編集対象として登録され、バウンズに合わせてラティスボックスが自動配置されて**即座に編集モードが有効化**されます。
- **複数のオブジェクトを選択した状態で追加した場合：**
  選択中のメッシュが**すべて変形対象として登録**され、ラティスボックスはそれら全体を包むように配置されます。コンポーネント自体は 1 つだけ、次の順で決まるオブジェクトに付きます。
  1. **右クリックしたオブジェクト**（付けたいオブジェクトの上で右クリックしてください。選択中であれば、メッシュを持たない親オブジェクトなどにも付けられます）
  2. 上部メニューなど、右クリック以外から実行した場合は、最後にクリックして選択したメッシュ
  3. それも判別できない場合は、選択中のメッシュのうちヒエラルキーで一番上にあるもの
- **Renderer のないオブジェクトに追加した場合：**
  コンポーネントのみが追加されます。Inspector の「対象を追加」欄から変形したい Renderer を指定してください。

コンポーネントが付いたオブジェクトは、ヒエラルキー上で一瞬ハイライトされます。

あとから対象を増やしたいときは、Inspector の「変形対象」の一番下にある **「対象を追加」の空欄へ、メッシュを持つオブジェクトをドラッグ＆ドロップ**します。複数まとめてドロップすることもできます。
服と素体を同時に登録しておくと、同じラティス空間で一緒に破綻なく変形させることができます。

### 2. 編集する

Inspector の **「編集開始」** ボタンを押すと、シーンビューが編集モードになります。

| 操作 | 動作 |
| --- | --- |
| 制御点をクリック | 単一の制御点を選択（選択中はオレンジの二重円） |
| **Shift + 制御点をクリック** | 選択の追加 / 解除（トグル） |
| **何もない場所からドラッグ** | **矩形範囲内の制御点を一括選択**（Shift併用で追加選択） |
| 移動ハンドルをドラッグ | 選択中の制御点を動かし、ボックス内のメッシュを滑らかに変形 |
| Esc | 制御点の選択を解除。選択がない状態でもう一度押すと編集終了 |
| 別のオブジェクトを選択 | 編集終了 |

シーンビュー右下の操作パネル（オーバーレイ）で、格子数・ミラー・ボックス操作をその場で変更できます。

### やり直し（Undo / Redo）

**ハンドルを掴んで動かす 1 動作が Undo 1 回分**です。`Ctrl+Z` を押すと、直前のドラッグだけが瞬時に取り消されます（`Ctrl+Y` で Redo）。
Prefab インスタンス上でもフリーズすることなく軽快に動作します。

### 3. そのままアップロード

保存操作やモディファイアの事前適用は不要です。編集結果はコンポーネントに保存され、アバターのアップロード時（ビルド時）に NDMF 経由で自動的に適用されます。

## シーンビュー操作パネル（オーバーレイ）

シーンビュー右下（ドラッグで移動可能）のパネルから、編集中によく使う設定を切り替えられます。

### 格子数（Resolution）
X / Y / Z 各軸の分割数を `[-]` `[数値]` `[+]` で即座に変更できます。
**格子数を途中で変更しても、これまでに加えたメッシュの変形形状は失われません。**（大まかに変形した後に格子を細かくして微調整する、といった往復が自由に行えます）。

### ミラー（Mirror）
`[ X ]` `[ Y ]` `[ Z ]` ボタンで対称変形を切り替えます。
- いずれかの軸をクリックすると、その軸が ON（緑色ハイライト）になりミラー変形が有効になります。
- 選択中の軸を再度クリックすると OFF になります。
- 左右対称に変形したい場合は、ラティスボックスをアバターの中心に合わせてください（「中心へ」ボタン）。

### ボックスを操作（Edit Box）
ラティスボックス自体の位置・回転・サイズを調整するモードに切り替えます。
- **移動 / 回転 / スケール**: シーンビュー上の各ハンドルでボックスの範囲を調整できます。
- **フィット（Fit）**: 変形対象のメッシュ全体を包み込むようにボックスを自動配置します。
- **中心へ（Center）**: アバターの対称面（X=0）に合わせてボックスの位置と回転をリセットします。

### 制御点をリセット（Reset Cage）
メッシュの変形結果を保ったまま、制御点を素の格子位置へ戻します。変形によって膨らんだメッシュに合わせてボックスサイズも自動再フィットされます。

## 補間方式（Interpolation）

変形の影響をどのように周囲へ広げるかを Inspector から設定できます。

| 方式 | 特徴 |
| --- | --- |
| **三線形 (Trilinear)** | 制御点の近傍セルだけが動きます。シャープで局所的な変形に向いています。 |
| **B-Spline** | 最も滑らかに変形します。自然な曲面を作りたい場合に適しています（制御点そのものの上は通りません）。 |
| **Catmull-Rom** | 制御点上を通過しつつ、滑らかな補間を行います。直感的な操作と滑らかさのバランスが良い方式です。 |

## ベイク

編集結果を適用したメッシュを、新規アセットファイルとしてプロジェクト内に書き出せます。

- 保存先は **元メッシュと同じフォルダ**
- 名前は元メッシュ名に **`_lattice`** を付けたもの
- 同名ファイルがある場合は末尾に連番が付与されます

### シェイプキーとして追加
チェックを入れてベイクすると、元のメッシュ形状を保ったまま、**変形分を新しいシェイプキー（BlendShape）として追加**したメッシュが出力されます。
Inspector の「シェイプキー名」から名前を指定できます（空の場合は元メッシュ名 + `_lattice`）。

> **注意：** ベイクはメッシュファイルを書き出す機能です。シーン内の Renderer は自動で差し替わりません。書き出したメッシュを使用したい場合は手動で Renderer の Mesh に割り当ててください。通常の VRChat アップロード時はベイク不要です。

## 仕様と制限

### できること
- 3Dラティスによる直感的かつ滑らかな自由形状変形 (FFD)
- 複数メッシュ（素体・衣装・アクセサリー等）の同時変形
- 格子解像度 (X, Y, Z) の非破壊な自由変更
- 任意軸 (X, Y, Z) でのミラー対称編集
- 矩形選択による複数制御点の一括操作
- NDMF プレビューへのリアルタイム反映
- メッシュの書き出しおよび BlendShape 化ベイク

### できないこと（意図的な仕様）
- 頂点・面の追加や削除（トポロジの変更）
- UV・法線・ボーンウェイトの直接編集

### 法線について
**法線・接線は再計算しません。** 大きく変形させると陰影が形状に追従しませんが、再計算によるシェーディング崩れを防ぐため意図的にこの仕様にしています。

### 頂点インデックスへの依存について
本ツールはシェイプキーと同様に、**元メッシュの頂点インデックスに対して差分（デルタ）を保持・適用**します。
- FBX の再インポート等で頂点順序が変化するとズレが生じる場合があります。
- メッシュの差し替え等で頂点数が編集時と異なっている場合、誤変形を防ぐため**自動的に安全に適用がスキップ**され、警告が表示されます。

### 他ツールとの関係
ビルド時は Transforming フェーズで処理するため、メッシュ最適化を行う Avatar Optimizer (AAO) よりも先に適用され、安全に共存できます。

## トラブルシューティング

### 「NDMF プレビュー未取得」と表示される
NDMF のプレビューが無効になっているか、生成待ちの状態です。
Unity のメニューバーまたはツールバーから NDMF のプレビューが有効になっているか確認してください。

### 「頂点数が編集時と異なります」と表示される
元メッシュが差し替わったか、FBX の再インポートで頂点数が変わっています。
誤った頂点が動くのを防ぐため変形はスキップされます。Inspector の「変形をすべて消去」でリセットして再調整してください。

### 編集が反映されない
- コンポーネントおよび GameObject が有効（Active）になっているか
- 対象 Renderer が正しく設定されているか
- NDMF のプレビューが有効になっているか

を確認してください。

### 編集中、形状とずれたオレンジの輪郭が重なって見づらい

編集中に見えている形状は NDMF のプレビューですが、選択アウトライン（オレンジの輪郭）と
選択ワイヤーフレームは**編集前の形状**で描かれるため、動かした頂点の上にずれた線が残ります。

Scene ビュー右上の **Gizmos メニュー → Selection Outline**（およびその下の Selection Wire）を
OFF にすると消えます。Unity 全体の設定なので、編集が終わったら戻してください。

> v1.0.2 まではこれをツール側で自動的に抑制していましたが、Unity 全体の設定を書き換える方式で
> 副作用が大きかったため廃止しました。旧バージョンを使ったあとアウトラインが表示されなく
> なっている場合も、同じ Gizmos メニューから ON に戻せます。
