 変形を確定させずに格子の数を変更しながらメッシュの変形ができるNDMF対応の非破壊ラティス変形Unity拡張機能を作ろうと思います。


Unity2022.3.22f1〜Unity6以降まで使えるようにします。


要件を整理してください。類似ツールも調査し、あると良い機能は要件に取り入れてください。


ターゲットはVRCユーザーです。


ラティス変形ではありませんが、dennokoworksのdennoko Mesh Editorと同じコンセプトでラティス変形版を作るつもりです。 
dennoko mesh editorのパスはこのワークスペースに対して ../DennokoMeshEditor/ です。

操作のフローなどはdennoko Mesh Editorと同様に最低限の操作回数で効率的に扱えるようにし、編集中のUIからはラティスの格子数の変更やミラーの有効化（軸設定込み）などの設定ができるようにします。

また、格子数変更などに対応するために、通常のラティス変形ツールのようにラティスの情報を保持するのではなく、それによって変形された頂点ごとの変形量を保持するような構成にします。

デフォルトの格子数は3×3とします。

ラティスの変化量は
- 三線形補間（Trilinear Interpolation）/ B-Spline FFD:
- B-Spline / Catmull-Rom
を一旦実装してください。 これらのデフォルトはとりあえず三線形補間とし、inspectorで切り替えられるようにします。

Undo Redo対応もdennoko Mesh Editorと同様に対応してください。ベイク周りも同様に実装してください。

基本的には dennoko mesh editor と同様に実装しながら、頂点の動かし方やラティスの制御項目だけを変えるようなイメージです。
